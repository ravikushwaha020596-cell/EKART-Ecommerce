# 🛒 Ekart - E-Commerce Website

A full-stack MERN e-commerce application where users can browse products, manage cart, place orders, make payments, and manage their accounts.

## 🚀 Features

### User Features
- User Registration & Email Verification
- Login / Logout with JWT Authentication
- Forgot Password with OTP Verification
- Reset Password
- Update Profile
- Upload Profile Picture
- View Order History
- Add to Cart
- Manage Addresses
- Online Payment with Razorpay

### Admin Features
- Admin Dashboard
- Add Products
- Update Products
- Delete Products
- Manage Users
- View Orders
- Sales Analytics

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- Shadcn UI
- Redux Toolkit
- Redux Persist
- React Router
- Axios
- Recharts

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Cloudinary
- Multer
- Nodemailer
- Razorpay Payment Gateway
